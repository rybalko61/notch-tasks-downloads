# Notch Tasks

Мини-приложение с задачами для macOS. Открывается у бровки MacBook; на Mac без выреза и внешних дисплеях доступно через значок в строке меню. Задачи хранятся только на вашем Mac.

## Скачать и установить

Скачайте ZIP-архив приложения из [релиза v0.1.1](https://github.com/rybalko61/notch-tasks-downloads/releases/tag/v0.1.1), распакуйте его и перетащите **Notch Tasks.app** в папку «Программы» (Applications). Поддерживаются macOS 14 Sonoma и новее, Mac с Apple Silicon. Версии для Intel пока нет.

При первом запуске откройте приложение через Finder. Поскольку тестовая сборка пока не нотарифицирована Apple, macOS может заблокировать запуск. Если вы скачали приложение именно из официального релиза этого репозитория и доверяете ему, разрешите запуск так:

1. Откройте **Системные настройки**.
2. Выберите **Конфиденциальность и безопасность** и прокрутите вниз до раздела «Безопасность».
3. Рядом с сообщением о заблокированном приложении нажмите **«Всё равно открыть»** (Open Anyway).
4. Подтвердите действие кнопкой **«Открыть»** и при необходимости подтвердите его паролем или Touch ID.

Если вы не уверены в источнике файла, отмените запуск. **Не отключайте Gatekeeper и другие средства защиты macOS целиком.** Названия кнопок могут немного отличаться в зависимости от версии macOS. Подробнее — [в инструкции Apple](https://support.apple.com/102445).

Обновления пока устанавливаются вручную: скачайте новую версию из раздела [Releases](https://github.com/rybalko61/notch-tasks-downloads/releases) и замените приложение в папке «Программы».

# Notch Tasks

Мини-приложение с задачами для macOS. Открывается у бровки MacBook; на других экранах доступно через значок в строке меню. Задачи хранятся только на вашем Mac.

## Скачать

Первая тестовая сборка готовится. Когда она появится, скачивайте файл только в разделе [Releases](https://github.com/rybalko61/notch-tasks-downloads/releases) этого репозитория. Исходный код здесь не публикуется.

Поддержка первой версии: macOS 14 или новее, Mac с Apple Silicon. Версии для Intel пока нет.

## Важное предупреждение для тестовой версии

До оформления Apple Developer Program приложение не подписано сертификатом Developer ID и не нотарифицировано Apple. macOS может предупредить о неизвестном разработчике и не открыть его автоматически. Не отключайте защиту Gatekeeper глобально. Если решите запустить тестовую версию, ознакомьтесь с [объяснением Apple](https://support.apple.com/102445) и загружайте файл только с этой страницы.

Обновления пока устанавливаются вручную.
